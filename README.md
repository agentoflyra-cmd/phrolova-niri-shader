# Flolo Niri Window Animations

这是一组给 Niri 使用的窗口开关动画，风格偏「柔和、花海、薰衣草、淡粉高光」。

设计上没有选择强烈的 glitch、破碎、燃烧或高频噪点效果，而是更贴近弗洛洛的气质：干净、轻盈、梦幻，带一点花瓣和柔光感。

## Window Open

窗口展开使用的是柔和浮现效果。

它不做花瓣凝聚，因为反向花瓣动画很容易看起来像碎纸片、脏点或者噪声糊出来。打开窗口时只保留轻微的水波折射、空气扰动和淡淡的薰衣草/粉色柔光，让窗口像是从光幕里自然浮现出来。

整体感觉：

```text
轻微折射 → 柔光浮现 → 窗口正常展开
```

适合日常使用，不会太抢眼，也不会影响窗口内容识别。

## Window Close

窗口关闭使用的是花瓣消散效果。

关闭时，窗口内容会被风轻轻吹散，边缘带一点薰衣草和淡粉色高光。这里没有使用高频随机噪点，而是通过低频分布、椭圆形 mask、随机旋转和风向漂移来模拟花瓣，让消失效果更像「花瓣被风带走」，而不是普通 dissolve 噪声。

整体感觉：

```text
窗口淡出 → 边缘发光 → 薰衣草花瓣随风散开
```

这个方向比“打开时花瓣反向拼合”自然很多，也更适合弗洛洛这种花海、白裙、柔光系主题。

## Design Choice

最终组合是：

```text
window-open  = soft veil / light ripple fade in
window-close = lavender petal dissolve
```

也就是：

* 打开：干净、轻柔、像光中浮现
* 关闭：浪漫、花瓣化、随风消散

这样窗口出现时不会显脏，窗口消失时又有足够的主题感。
